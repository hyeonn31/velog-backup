# 몸을 움직이는 필수 지식
몸을 움직이는 애니메이션을 만들때,
절대적으로 필요한 지식이다.

## 🟢 FK (Forward Kinematics, 정방향 운동학)
> **"원인으로부터 결과"**를 생각하는 방법 

### 정의

- 부모 본(bone)을 움직이면 자식 본이 따라가는 방식.
- 계층 구조의 윗부분 → 아랫부분 순서로 움직임이 전달됩니다.
- 예: 어깨를 돌리면 팔꿈치 → 손목 순서로 같이 따라감.

### 언제 쓰나?

- 팔을 자연스럽게 흔드는 동작, 큰 동작(예: 캐릭터 전체 포즈 잡기).
- 걷거나 뛰는 애니메이션에서 팔, 척추, 꼬리, 머리카락 같은 부드러운 흐름 있는 움직임 만들 때.

### 장점
✔ 직관적임 (본 구조 그대로 따라감)
✔ 각 본마다 컨트롤 가능 → 섬세한 동작 표현 용이
✔ 자연스러운 아크(arc) 모션을 만들기 쉬움

### 단점
✘ 원하는 위치에 손·발 같은 끝부분을 정확히 두기 어려움
✘ 모든 본을 하나하나 조정해야 해서 작업이 번거로움

.

## 🟢 FK 애니메이션 예시 (Forward Kinematics)

**1. 상황**: 캐릭터가 팔을 휘두르며 걷는 장면

**2. 방법**:
- 어깨 본 → 팔꿈치 본 → 손목 본 순서로 회전값을 직접 조정.
- 부모 본(어깨)을 돌리면 아래 자식 본들이 따라오면서 자연스러운 호(arc) 모션이 생김.

**3. 특징**:
- 부드럽게 흔들리는 동작에 적합.
- 하지만 손 위치를 특정 지점에 고정하기는 힘듦.
- 예: 캐릭터가 가볍게 손을 흔들며 인사하는 모션.

## 🔵 IK (Inverse Kinematics, 역운동학)

> **"결과에서 원인"**을 생각하는 방법

### 정의

- 자식 본(끝부분)을 움직이면 부모 본들이 자동으로 계산되어 따라오는 방식.
- 계층 구조의 아랫부분 → 윗부분으로 움직임이 전달됩니다.
- 예: 손을 특정 위치에 두면 어깨, 팔꿈치가 자동으로 맞춰짐.

### 언제 쓰나?

- 발이 바닥에 닿아있게 유지하거나(워킹, 러닝)
- 손이 문 손잡이, 무기, 물체 등을 붙잡고 있어야 할 때.
- 즉, 끝 위치를 고정해야 하는 애니메이션에 적합.

### 장점
✔ 손·발 같은 끝부분을 원하는 위치에 정확히 고정 가능
✔ 걷기, 뛰기처럼 접지(contact)가 중요한 애니메이션에 유리
✔ 조작이 빠름 (한 컨트롤러로 팔/다리 전체 움직임 제어 가능)

### 단점
✘ 자동 계산이므로 관절 모양이 부자연스럽게 꺾일 수 있음
✘ FK처럼 세밀한 아크 모션 만들기 어려움
✘ 무리하게 쓰면 어색한 자세가 나올 수 있음

## 🔵 IK 애니메이션 예시 (Inverse Kinematics)

 **1. 상황**: 캐릭터가 문 손잡이를 잡고 있는 장면

 **2. 방법**:
- 손목에 있는 IK 컨트롤러를 문 손잡이 위치에 고정.
- 블렌더가 팔꿈치와 어깨 본 각도를 자동 계산해서 팔이 따라옴.
- 애니메이터는 손 컨트롤러 하나만 움직여도 손이 제자리에 고정됨.

**3. 특징:**

- 손·발이 특정 물체에 닿아있거나 바닥에 닿아야 하는 경우 유용.
- 하지만 자연스러운 흐름 있는 움직임(FK의 아크 모션)은 만들기 힘듦.
- 예: 캐릭터가 걷다가 발이 땅에 착 붙어 있는 동작.


---

## 🔄 혼합 사용 예시

- 걷기 애니메이션:

  - 다리는 IK → 발이 바닥에 자연스럽게 붙도록.
  - 팔은 FK → 어깨에서 자연스럽게 흔들리도록.

- 물건 잡기:

  - 팔 움직임은 IK → 손이 물체를 놓치지 않도록.
  - 물건을 들고 나서 흔드는 동작은 FK → 자연스러운 흔들림 표현.

## 🔶 FK vs IK 비교표
| 구분         | FK (Forward Kinematics)        | IK (Inverse Kinematics)         |
| ---------- | ------------------------------ | ------------------------------- |
| **움직임 방향** | 부모 → 자식                        | 자식(끝) → 부모                      |
| **예시**     | 마론 인형 (위에서 아래로)                | 줄인형, 마리오네트 (손·발 먼저 움직임)         |
| **적합한 상황** | 팔 휘두르기, 꼬리/척추 움직임, 자연스러운 곡선 모션 | 손·발 고정(바닥, 물체 잡기), 무기 잡기, 발 딛기  |
| **장점**     | 섬세하고 자연스러운 동작                  | 손·발 위치를 쉽게 고정                   |
| **단점**     | 끝 위치 고정하기 힘듦                   | 자연스러운 곡선 동작 어렵고, 어색한 자세 나올 수 있음 |

---

## 정리 👉:

**FK** = 자연스러운 곡선/흐름 동작
**IK** = 끝점 고정/물체 접촉 동작

실전에서는 혼합해서 쓰는 게 정석

👉 실제 애니메이션 작업에서는 FK와 IK를 혼합해서 사용하는 경우가 많음.
예: 캐릭터가 걸을 때 다리는 IK로 바닥에 고정, 팔은 FK로 자연스럽게 흔들림.
