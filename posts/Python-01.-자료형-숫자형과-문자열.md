## 1. 숫자형 (Number)

숫자형은 말 그대로 숫자를 다루는 자료형이다. 정수(`int`)와 실수(`float`)가 대표적이다.

```python
a = 3      # 정수(int)
b = 3.14   # 실수(float)
```

### 1-1. 산술 연산자

| 연산자 | 의미 | 예시 (`a=3, b=4`) | 결과 |
|---|---|---|---|
| `+` | 덧셈 | `a + b` | `7` |
| `-` | 뺄셈 | `a - b` | `-1` |
| `*` | 곱셈 | `a * b` | `12` |
| `/` | 나눗셈 | `a / b` | `0.75` |
| `//` | 몫 (나눗셈 후 소수점 버림) | `a // b` | `0` |
| `%` | 나머지 | `a % b` | `3` |
| `**` | 거듭제곱 | `a ** b` | `81` (3⁴) |

```python
a = 3
b = 4

print(a + b)   # 7
print(a * b)   # 12
print(a / b)   # 0.75
print(a // b)  # 0
print(a ** b)  # 81
print(a % b)   # 3
```

**헷갈리기 쉬운 부분**

- `/` 연산의 결과는 **항상 실수(float)** 다. `4 / 2`도 `2`가 아니라 `2.0`이 나온다.
- `//`는 나눗셈의 **몫**만 구한다. `3 // 4`는 0.75에서 소수점을 버려서 `0`이 된다.
- `%`는 **나머지**를 구한다. 짝수/홀수 판별(`n % 2 == 0`)처럼 자주 쓰인다.

### 1-2. 변수 값 갱신하기

```python
a = a + 1
print(a)   # 4
```

수학에서 `a = a + 1`은 성립하지 않는 식이지만, 프로그래밍에서 `=`는 **"같다"가 아니라 "대입한다"** 는 뜻이다.
즉, **오른쪽(`a + 1`)을 먼저 계산하고 그 결과를 왼쪽 변수 `a`에 다시 저장**한다는 의미다.

같은 코드를 줄여서 `a += 1`로 쓸 수도 있다. (`-=`, `*=`, `/=` 등도 같은 방식이다.)

## 2. 문자열 (String)

문자열은 문자, 단어 등으로 구성된 **문자들의 집합**이다. 따옴표로 감싸서 만든다.

### 2-1. 문자열을 만드는 4가지 방법

```python
'a'          # 작은따옴표
"a"          # 큰따옴표
'''a'''      # 작은따옴표 3개
"""a"""      # 큰따옴표 3개
```

네 가지 모두 같은 문자열을 만든다. 그런데 왜 이렇게 방법이 여러 개일까?
**문자열 안에 따옴표가 들어가는 경우**와 **여러 줄 문자열**을 편하게 다루기 위해서다.

### 2-2. 문자열 안에 따옴표 넣기

**방법 1. 다른 종류의 따옴표로 감싸기**

문자열 안에 작은따옴표(`'`)가 있으면 바깥은 큰따옴표(`"`)로 감싼다.

```python
a = "python's"
print(a)   # python's
```

만약 `'python's'`처럼 쓰면 파이썬은 `'python'`까지를 문자열로 인식하고, 뒤의 `s'`에서 문법 오류가 발생한다.

**방법 2. 백슬래시(`\`)로 이스케이프하기**

따옴표 앞에 `\`를 붙이면 "문자열을 끝내는 기호"가 아니라 **"문자 그대로의 따옴표"** 로 인식한다.

```python
b = '\"python is very easy. \"he says.'
print(b)   # "python is very easy. "he says.
```

### 2-3. 이스케이프 코드

`\`와 특정 문자를 조합하면 줄바꿈, 탭처럼 **눈에 보이지 않는 문자**를 표현할 수 있다.
이런 조합을 **이스케이프 코드(escape code)** 라고 한다.

| 코드 | 의미 |
|---|---|
| `\n` | 줄바꿈 (new line) |
| `\t` | 탭 (tab) |
| `\\` | 백슬래시 문자 자체 |
| `\'` | 작은따옴표 문자 |
| `\"` | 큰따옴표 문자 |

```python
print("python \t is \nvery easy.")
```

```
python 	 is 
very easy.
```

`\t` 자리에는 탭 간격이, `\n` 자리에서는 줄이 바뀐 것을 확인할 수 있다.

### 2-4. 여러 줄 문자열 (멀티라인)

여러 줄짜리 문자열은 `\n`을 여러 번 쓰는 대신 **따옴표 3개**로 감싸면 입력한 그대로 저장된다.

```python
mul = '''
Apple
Banana
'''
print(mul)

mul = """
Apple
Banana
"""
print(mul)
```

```

Apple
Banana

```

> 출력 결과 위아래에 빈 줄이 생기는 이유는 `'''` 바로 뒤와 `'''` 바로 앞의 **줄바꿈도 문자열에 포함**되기 때문이다.

## 3. 문자열 연산

파이썬은 문자열끼리 **더하고(+)**, 문자열에 숫자를 **곱할(\*)** 수 있다.

### 3-1. 더하기 (연결)

```python
head = " Python"
tail = " is easy."
print(head + tail)   #  Python is easy.
```

`+`는 두 문자열을 **이어 붙인다**.

### 3-2. 곱하기 (반복)

```python
print(head * 3)      #  Python Python Python
print("=" * 50)      # ==================================================
```

`문자열 * n`은 문자열을 **n번 반복**한다.
`"=" * 50`처럼 출력 결과를 구분하는 선을 그릴 때 유용하다.

> ⚠️ `"3" + 3`처럼 문자열과 숫자를 더하면 `TypeError`가 발생한다. 자료형이 다르면 더할 수 없다.

### 3-3. 문자열 길이 - `len()`

```python
a = "Life is too short"
print(len(a))   # 17

b = len(a)      # 결과를 변수에 저장할 수도 있다
print(b)        # 17
```

`len()`은 문자열의 문자 개수를 돌려주는 **파이썬 내장 함수**다. **공백도 한 글자로 센다.**

### 3-4. 인덱싱 (Indexing)

**인덱싱**은 문자열에서 **특정 위치의 문자 하나**를 꺼내는 것이다. `문자열[번호]` 형태로 쓴다.

```python
a = "life is too short, you need python"
print(a[3], a[0], a[12], a[-1], a[-2], a[-5])
# e l s n o y
```

인덱싱에서 기억할 두 가지:

1. **번호는 0부터 시작한다.** 첫 번째 문자는 `a[1]`이 아니라 `a[0]`이다.
2. **음수 번호는 뒤에서부터 센다.** `a[-1]`은 마지막 문자, `a[-2]`는 뒤에서 두 번째 문자다.

```
문자열:   l  i  f  e     i  s  ...  t  h  o  n
인덱스:   0  1  2  3  4  5  6  ...
음수:                           ... -4 -3 -2 -1
```

## 4. 문자열 슬라이싱 (Slicing)

인덱싱이 문자 **하나**를 꺼낸다면, **슬라이싱**은 문자열의 **일부분을 잘라** 꺼낸다.

```python
문자열[시작번호:끝번호]
```

> ⭐ 가장 중요한 규칙: **시작 번호는 포함하고, 끝 번호는 포함하지 않는다.**
> `a[0:4]`는 `a[0]`, `a[1]`, `a[2]`, `a[3]`까지만 가져온다. (`a[4]`는 제외)

```python
a = "life is too short, you need python"

a[0:4]     # 'life'                    → 0~3번
a[5:7]     # 'is'                      → 5~6번
a[12:]     # 'short, you need python'  → 끝 번호를 생략하면 문자열 끝까지
a[19:-7]   # 'you need'                → 음수 인덱스도 사용 가능
```

번호를 생략하는 규칙은 다음과 같다.

| 형태 | 의미 |
|---|---|
| `a[:4]` | 처음부터 3번까지 |
| `a[12:]` | 12번부터 끝까지 |
| `a[:]` | 처음부터 끝까지 (전체) |

### 4-1. 활용 예: 문자열 나누기

슬라이싱은 **형식이 정해진 문자열**을 나눌 때 특히 유용하다.
예를 들어 `"날짜 8자리 + 날씨"` 형식의 문자열이 있다면, 위치를 기준으로 잘라낼 수 있다.

```python
a = "20203331Rainy"

year    = a[0:4]   # '2020'
month   = a[4:6]   # '33'
day     = a[6:8]   # '31'
weather = a[8:]    # 'Rainy'

year, month, day, weather
# ('2020', '33', '31', 'Rainy')
```

> 💡 Jupyter에서는 셀의 마지막 줄에 변수를 쉼표로 나열하면 `print()` 없이도 값을 한꺼번에 확인할 수 있다. (결과는 튜플 형태로 출력된다.)

### 참고: 문자열은 수정할 수 없다

```python
a = "Pithon"
a[1] = "y"   # TypeError: 'str' object does not support item assignment
```

문자열은 **변경 불가능한(immutable)** 자료형이라, 인덱싱으로 특정 문자만 바꿀 수 없다.
대신 슬라이싱으로 잘라서 **새 문자열을 만들어야** 한다.

```python
a = a[:1] + "y" + a[2:]   # 'Python'
```

## 5. 문자열 포매팅 (String Formatting)

**문자열 포매팅**이란 문자열 안의 특정 위치에 **값을 끼워 넣는 것**이다.

예를 들어 `"사과를 3개 먹었다"`, `"사과를 5개 먹었다"`처럼 숫자만 바뀌는 문장을 매번 새로 만드는 대신,
틀을 하나 만들어 두고 값만 바꿔 넣을 수 있다.

파이썬에는 세 가지 포매팅 방법이 있다.

| 방법 | 형태 | 특징 |
|---|---|---|
| 1. `%` 연산자 | `"%d개" % 3` | 오래된 방식 (C 언어 스타일) |
| 2. `format()` 함수 | `"{0}개".format(3)` | `%`보다 유연함 |
| 3. f-string | `f"{num}개"` | **Python 3.6 이상**, 가장 간결하고 많이 쓰임 |

### 5-1. `%` 포매팅

문자열 안에 `%d`, `%s` 같은 **포맷 코드**를 넣고, 문자열 뒤에 `% 값`을 붙인다.

| 포맷 코드 | 의미 |
|---|---|
| `%s` | 문자열 (String) |
| `%d` | 정수 (Decimal) |
| `%f` | 실수 (Floating-point) |
| `%%` | `%` 문자 자체 |

```python
# 숫자 대입
"i eat %d apples." % 3         # 'i eat 3 apples.'

# 실수 대입 - 기본적으로 소수점 6자리까지 표시된다
"i eat %f apples." % 3.4       # 'i eat 3.400000 apples.'

# 문자열 대입
"i eat %s apples." % "five"    # 'i eat five apples.'

# 변수로 대입
num = 3
"i eat %d apples." % num       # 'i eat 3 apples.'
```

> 💡 `%s`는 숫자를 넣어도 자동으로 문자열로 바꿔서 넣어 준다. 어떤 값을 넣을지 애매할 때 쓸 수 있다.

**`%` 문자 자체를 쓰고 싶을 때**

포매팅을 쓰는 문자열 안에서 `%`는 포맷 코드의 시작으로 인식된다.
그래서 `%` 문자를 그대로 출력하려면 `%%`처럼 **두 번** 써야 한다.

```python
"error is %d%%" % 98           # 'error is 98%'
```

#### 정렬과 공백

`%`와 포맷 코드 사이에 숫자를 넣으면 **전체 자리 수(폭)** 를 지정할 수 있다.

```python
"%10s" % "hi"     # '        hi'  → 전체 10칸 중 오른쪽 정렬, 남은 8칸은 공백
"%-10s" % "hi"    # 'hi        '  → 앞에 -를 붙이면 왼쪽 정렬
```

#### 소수점 표현

`.숫자`로 소수점 아래 자리 수를 정할 수 있다.

```python
"%.3f" % 3.42134234    # '3.421'  → 소수점 아래 3자리까지
"%5.3f" % 3.42134234   # '3.421'  → 전체 5칸, 소수점 아래 3자리
```

`%5.3f`에서 `5`는 **소수점(`.`)까지 포함한 전체 폭**이다.
`'3.421'`은 이미 5글자라서 공백이 추가되지 않았다. `%10.3f`로 바꾸면 앞에 공백 5칸이 생긴다.

### 5-2. `format()` 함수

문자열 안에 `{}`를 넣고, `.format()`에 넣을 값을 전달한다.

```python
"I eat {0} apples".format(3)
# 'I eat 3 apples'
```

**값 여러 개 넣기 - 인덱스로**

`{0}`, `{1}`처럼 번호를 쓰면 `format()`에 전달한 **순서대로** 값이 들어간다.

```python
"i eat {0} apples. so i was sick for {1} days.".format(3, 5)
# 'i eat 3 apples. so i was sick for 5 days.'
```

**값 여러 개 넣기 - 이름으로**

`{number}`처럼 이름을 쓰고 `format(number=10)` 형태로 넘기면, 순서를 신경 쓰지 않아도 되고 코드도 읽기 쉬워진다.

```python
"i ate {number} apples. so i was sick for {day} days.".format(number=10, day="three")
# 'i ate 10 apples. so i was sick for three days.'
```

#### 정렬과 공백 채우기

`{0:정렬기호폭}` 형태로 쓴다. 정렬 기호 앞에 **문자 하나**를 쓰면 공백 대신 그 문자로 빈칸을 채운다.

| 기호 | 의미 |
|---|---|
| `<` | 왼쪽 정렬 |
| `>` | 오른쪽 정렬 |
| `^` | 가운데 정렬 |

```python
"{0:<10}".format("hi")      # 'hi        '  → 왼쪽 정렬, 전체 10칸
"{0:=>10}".format("hi")     # '========hi'  → 오른쪽 정렬, 빈칸을 = 로 채움
"{0:=^10}".format("hi")     # '====hi===='  → 가운데 정렬, 빈칸을 = 로 채움
```

`{0:=>10}`을 풀어 읽으면 **"0번 값을 / `=`로 채우면서 / 오른쪽(`>`) 정렬 / 전체 10칸"** 이다.

#### 소수점 표현

```python
y = 3.42134234
"{0:0.4f}".format(y)        # '3.4213'  → 소수점 아래 4자리
```

#### 중괄호 `{ }` 문자 자체를 쓰고 싶을 때

`format()`에서는 `{}`가 값이 들어갈 자리를 뜻하므로, 중괄호를 그대로 출력하려면 `{{`, `}}`처럼 **두 번** 쓴다.

```python
"{{ and }}".format()        # '{ and }'
```

### 5-3. f-string (Python 3.6 이상)

문자열 앞에 **`f`** 를 붙이고, `{}` 안에 **변수 이름을 바로** 쓴다.
`format()`처럼 값을 따로 넘길 필요가 없어서 가장 간결하고, 요즘 가장 많이 쓰는 방법이다.

```python
number = 3
day = 5
f"i ate {number} apples. so i was sick for {day} days."
# 'i ate 3 apples. so i was sick for 5 days.'
```

```python
name = "홍길동"
age = 30
f"나의 이름은 {name}입니다. 나이는 {age}입니다."
# '나의 이름은 홍길동입니다. 나이는 30입니다.'
```

**`{}` 안에 수식도 쓸 수 있다**

f-string의 큰 장점은 `{}` 안에서 **바로 계산**할 수 있다는 점이다.

```python
f"나의 이름은 {name}입니다. 나이는 {age}입니다. 내년이면 {age+1}살이 됩니다."
# '나의 이름은 홍길동입니다. 나이는 30입니다. 내년이면 31살이 됩니다.'
```

#### 정렬과 공백 채우기

`{값:채울문자정렬기호폭}` 형태로, `format()`과 규칙이 같다.

```python
print(f'{"hi":<10}')    # 'hi        '  왼쪽 정렬
print(f'{"hi":>10}')    # '        hi'  오른쪽 정렬
print(f'{"hi":^10}')    # '    hi    '  가운데 정렬

print(f'{"hi":=^10}')   # '====hi===='  = 로 채우기
print(f'{"hi":!<10}')   # 'hi!!!!!!!!'  ! 로 채우기
```

> 바깥을 작은따옴표(`'`)로 감쌌기 때문에 안쪽 문자열 `"hi"`는 큰따옴표로 썼다.

#### 소수점 표현

```python
y = 3.42134234
f'{y:0.4f}'     # '3.4213'      → 소수점 아래 4자리
f'{y:10.4f}'    # '    3.4213'  → 전체 10칸, 소수점 아래 4자리 (오른쪽 정렬)
```

#### 중괄호 문자 자체 출력

```python
f'{{ and }}'    # '{ and }'
```

### 5-4. 세 가지 방법 비교

같은 문장을 세 가지 방법으로 만들어 보면 차이가 한눈에 보인다.

```python
name = "홍길동"
age = 30

"이름: %s, 나이: %d" % (name, age)          # % 연산자
"이름: {0}, 나이: {1}".format(name, age)    # format()
f"이름: {name}, 나이: {age}"                # f-string
```

> 값을 여러 개 넣을 때 `%` 방식은 `(name, age)`처럼 **괄호로 묶어서** 전달한다.

| 기능 | `%` | `format()` | f-string |
|---|---|---|---|
| 오른쪽 정렬 (10칸) | `%10s` | `{0:>10}` | `{x:>10}` |
| 왼쪽 정렬 (10칸) | `%-10s` | `{0:<10}` | `{x:<10}` |
| 가운데 정렬 | ✗ | `{0:^10}` | `{x:^10}` |
| 공백 채우기 | ✗ | `{0:=^10}` | `{x:=^10}` |
| 소수점 4자리 | `%.4f` | `{0:.4f}` | `{x:.4f}` |
| 특수문자 이스케이프 | `%%` | `{{ }}` | `{{ }}` |

새로 작성하는 코드라면 **f-string**을 쓰는 것이 가장 읽기 쉽다.

## 6. 문자열 관련 함수 (메서드)

문자열 자료형은 자체적으로 여러 함수를 가지고 있다. `문자열.함수()` 형태로 사용한다.
이렇게 자료형에 딸린 함수를 **메서드(method)** 라고 부른다.

| 함수 | 기능 | 예시 | 결과 |
|---|---|---|---|
| `count(x)` | 문자 `x`의 개수 세기 | `"hobby".count("b")` | `2` |
| `find(x)` | `x`가 처음 나온 위치 (없으면 **-1**) | `"Python is the best choice".find("b")` | `14` |
| `index(x)` | `x`가 처음 나온 위치 (없으면 **오류**) | `"Life is too short".index("t")` | `8` |
| `join(x)` | `x`의 각 요소 사이에 문자열 삽입 | `",".join("abcd")` | `'a,b,c,d'` |
| `upper()` | 대문자로 변환 | `"hi".upper()` | `'HI'` |
| `lower()` | 소문자로 변환 | `"Hi".lower()` | `'hi'` |
| `lstrip()` | 왼쪽 공백 제거 | `" hi ".lstrip()` | `'hi '` |
| `rstrip()` | 오른쪽 공백 제거 | `" hi ".rstrip()` | `' hi'` |
| `strip()` | 양쪽 공백 제거 | `" hi ".strip()` | `'hi'` |

### 6-1. 문자 개수 세기 - `count()`

```python
a = "hobby"
a.count("b")    # 2
```

### 6-2. 위치 찾기 - `find()` vs `index()`

두 함수 모두 찾는 문자가 **처음 나온 위치(인덱스)** 를 돌려준다. 차이는 **찾지 못했을 때**의 동작이다.

```python
a = "Python is the best choice"
a.find("b")     # 14
a.find("k")     # -1  → 없으면 -1을 돌려줌 (오류 X)
```

```python
a = "Life is too short"
a.index("t")    # 8
a.index("k")    # ValueError: substring not found  → 없으면 오류 발생
```

| | 찾았을 때 | 못 찾았을 때 |
|---|---|---|
| `find()` | 위치 반환 | `-1` 반환 |
| `index()` | 위치 반환 | **`ValueError` 발생** |

문자가 없을 수도 있는 상황이라면, 프로그램이 멈추지 않는 `find()`가 다루기 편하다.

### 6-3. 문자열 삽입 - `join()`

`"구분자".join(대상)` 형태로, 대상의 **각 요소 사이에** 구분자를 끼워 넣는다.
쓰는 순서가 헷갈리기 쉬운데, **끼워 넣을 문자열이 앞에** 온다.

```python
",".join('abcd')                  # 'a,b,c,d'
```

문자열뿐 아니라 **리스트**에도 사용할 수 있다. 리스트를 하나의 문자열로 합칠 때 자주 쓴다.

```python
"#".join(['a', 'b', 'c', 'd'])    # 'a#b#c#d'
```

### 6-4. 대소문자 바꾸기 - `upper()`, `lower()`

```python
a = "hi"
b = "Hi"
print(a.upper())   # HI
print(b.lower())   # hi
```

> 영어 입력값을 비교할 때 `upper()`나 `lower()`로 통일하면 대소문자 구분 없이 비교할 수 있다.

### 6-5. 공백 지우기 - `strip()`, `lstrip()`, `rstrip()`

```python
a = " hi "
print(a.lstrip())   # 'hi '   → 왼쪽(left) 공백 제거
print(a.rstrip())   # ' hi'   → 오른쪽(right) 공백 제거
print(a.strip())    # 'hi'    → 양쪽 공백 제거
```

사용자 입력값 앞뒤에 실수로 들어간 공백을 정리할 때 유용하다.

> ⚠️ 문자열은 수정할 수 없는 자료형이기 때문에, `upper()`나 `strip()` 같은 함수는 **원본을 바꾸지 않고 새 문자열을 돌려준다.**
> 결과를 계속 쓰려면 `a = a.strip()`처럼 다시 대입해야 한다.

## 정리

- **숫자형**: `/`는 항상 실수, `//`는 몫, `%`는 나머지, `**`는 거듭제곱
- **문자열 만들기**: 따옴표 4가지. 따옴표가 섞이면 다른 따옴표나 `\`로 해결하고, 여러 줄은 `'''` / `"""`로 감싼다
- **문자열 연산**: `+`는 연결, `*`는 반복, `len()`은 길이
- **인덱싱**: 0부터 시작, 음수는 뒤에서부터
- **슬라이싱**: `[시작:끝]`에서 **끝 번호는 포함하지 않음**
- **포매팅**: `%` → `format()` → **f-string**(3.6+) 순으로 발전했고, 지금은 f-string을 가장 많이 쓴다
- **문자열 함수**: `find()`는 못 찾으면 -1, `index()`는 오류. 문자열 함수는 원본을 바꾸지 않는다
