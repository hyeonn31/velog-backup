처음에 react를 vscode에 설정하는 방법은 
vscode 터미널에서
![](https://cdn.jsdelivr.net/gh/hyeonn31/velog-backup@main/assets/eb1798adec329fcf.png)
> npx create-react-app (원하는 이름sh-app)

을 넣고 enter버튼을 누른다. 

프로젝트 생성이 완료되면 명령어를 친절하게 알려준다.
![](https://cdn.jsdelivr.net/gh/hyeonn31/velog-backup@main/assets/8478c7d835fb26db.png)

여기서 잠시 해당 명령어를 알아보자.
>
```jsx
#경로변경(change directory)
$ cd sh-app
#어플리케이션 실행
$ npm start
```
