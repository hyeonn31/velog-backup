## 파일 | File
 Ctrl + N: 새로 만들기
 Ctrl + O: 열기
 Ctrl + F4: 현재 프로젝트 닫기 (프로젝트 종료 X)
 Ctrl + S: 저장
 Ctrl + Shift + E: 텍스쳐 내보내기
 
 
 ## 편집 | Edit
 Ctrl + z: 실행취소
 Ctrl + Y: 다시 실행
 Ctrl + Shift + R: 메시 다시 가져오기
 Ctrl + Shift + B: 메시 맵 베이킹
 
 
 ## 화면 | View
 **F1~F4: 보기 모드**
 **- F1: 3D, 2D 보기(전체화면)**
 **- F2: 3D 보기(모델링)**
** - F3: 2D 보기(UV,텍스쳐)**
** - F4: 2D <-> 3D 보기 전환**
 F5: 원근시점 보기(Perspective)
 F6: 직각시점 보기(Orthographic)
 Tab: UI 숨기기
 
## 화면 조작 | Mouse Control
 Alt + 휠 드래그: 이동
 Alt + 클릭 드래그: 회전
 휠 위/아래: 확대/축소
 shift + 오른쪽 마우스 드래그 : 빛 방향 변경 (조명 각도 설정)
 ctrl + 오른쪽 마우스 드래그 : 브러쉬 크기 조정

## 뷰포트 |  Viewport
F:전체 메시 표시(Fit)

**M: 머테리얼 보기(컴플리트 맵 보기 변경)**
**B**: 다음 _**메시 맵**_ 표시
Shift + B: 이전 메시 맵 표시
**C: 다음 _채널_ 표시 (각 채널들에 대한 내용)**
Shift + C: 이전 채널 표시

Y: 빠른 마스크 사용
U: 빠른 마스크 편집
Ctrl + Shift + I: 빠른 마스크 반전

## 도구 | Tools
1: 페인트 / [ , ] 브러쉬 사이즈 조절 / Shift 누르고 클릭 : 직선으로 그리기
2: 지우개 / [ , ] 지우개 사이즈 조절 / Shift 누르고 클릭 : 직선으로 지우기 
3: 프로젝션 / S: 누른 상태로 조절
4: 폴리곤 모드(폴리곤 선택) / X: 흑백전환
5: 블러(스머지)
6: 도장(복제)
P: 색상추출(스포이드)
L: 좌우 대칭

## 모드 | Mode
F9: 페인팅
F10: 렌더링(lray)

## 레이어 | Layers
눈 하나 클릭하고 밑으로 쭉 드레그 하면 켜진다.
