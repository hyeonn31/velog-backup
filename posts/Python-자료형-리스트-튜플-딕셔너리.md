# [Python] 자료형 - 리스트, 튜플, 딕셔너리

지난 글에서는 숫자 하나, 문자열 하나처럼 **값 하나**를 다뤘다.
그런데 실제로 프로그램을 만들다 보면 값 여러 개를 한꺼번에 들고 다녀야 할 때가 훨씬 많다.

- 일주일 동안의 주식 가격 7개
- 내가 가진 자산 목록 (현금, 채권, ETF ...)
- "ETF는 3주, 채권은 2주" 같은 보유 현황

이렇게 **여러 값을 하나로 묶어 담는 자료형**을 **컬렉션(collection)** 이라고 부른다.
이번 글에서는 가장 많이 쓰는 세 가지, **리스트 · 튜플 · 딕셔너리**를 정리한다.

> 실습 환경: VS Code + Jupyter Notebook (Python 3.14)

---

## 0. 한눈에 비교하기

먼저 큰 그림부터 보고 들어가자. 세 가지를 생활 속 물건에 비유하면 이렇다.

| 자료형 | 비유 | 모양 | 순서 | 수정 | 값을 꺼내는 방법 |
|---|---|---|---|---|---|
| 리스트 `list` | 번호가 붙은 **사물함** | `[1, 2, 3]` | 있음 | **가능** | 번호(인덱스) |
| 튜플 `tuple` | 한 번 찍으면 못 고치는 **영수증** | `(1, 2, 3)` | 있음 | **불가능** | 번호(인덱스) |
| 딕셔너리 `dict` | 이름표가 붙은 **서랍장** | `{'ETF': 3}` | - | **가능** | 이름표(키) |

- 괄호 모양이 다 다르다: 리스트는 대괄호 `[ ]`, 튜플은 소괄호 `( )`, 딕셔너리는 중괄호 `{ }`.
- 이 표만 기억해도 이 글의 절반은 끝난 거다. 이제 하나씩 자세히 보자.

## 1. 리스트 (List)

### 1-1. 리스트 만들고 꺼내기

리스트는 값 여러 개를 대괄호 `[ ]` 안에 쉼표 `,`로 구분해서 넣으면 된다.

```python
a = [1, 2, 3]
```

리스트를 **번호가 붙은 사물함**이라고 생각해 보자. 칸이 3개 있고, 각 칸에 1, 2, 3이 들어 있다.

```
  칸 번호(인덱스):   0     1     2
                  ┌───┬───┬───┐
             a =  │ 1 │ 2 │ 3 │
                  └───┴───┴───┘
  뒤에서 세는 번호:  -3    -2    -1
```

여기서 정말 중요한 규칙이 하나 있다.

> ⚠️ **파이썬은 번호를 0부터 센다.**
> 첫 번째 칸은 `1번`이 아니라 `0번`이다. 처음엔 다들 여기서 한 번씩 틀린다.

칸에 든 값을 꺼낼 때는 `리스트이름[번호]`라고 쓴다. 이 번호를 **인덱스(index)** 라고 부른다.

```python
a = [1, 2, 3]
a[0], a[0] + a[2], a[-1]   # (1, 4, 3)
```

- `a[0]` → 0번 칸 → `1`
- `a[0] + a[2]` → 0번 칸(1) + 2번 칸(3) → `4`
- `a[-1]` → **마이너스 번호는 뒤에서부터** 센다. `-1`은 맨 끝 칸 → `3`

> 💡 `-1`은 "맨 마지막"이라는 뜻이라서 정말 자주 쓴다.
> 리스트 길이가 몇 개인지 몰라도 마지막 값을 바로 꺼낼 수 있기 때문이다.

### 1-2. 리스트 안에 리스트 (중첩 리스트)

사물함 한 칸에 **또 다른 작은 사물함**을 넣을 수도 있다.

```python
a = [1, 2, 3, ['a', 'b', 'c']]
a[-1]      # ['a', 'b', 'c']
```

`a[-1]`은 맨 끝 칸인데, 그 칸에 들어 있는 게 리스트 `['a', 'b', 'c']` 통째다.

그럼 그 안에 있는 `'b'`를 꺼내려면? **대괄호를 한 번 더** 붙이면 된다.

```python
a[-1][1]   # 'b'
```

왼쪽부터 차례대로 읽으면 쉽다.

1. `a[-1]` → 큰 사물함의 맨 끝 칸을 연다 → `['a', 'b', 'c']`
2. `[1]` → 그 안의 작은 사물함에서 1번 칸을 연다 → `'b'`

3단으로 겹쳐도 원리는 똑같다.

```python
a = [1, 2, ["a", "b", ["Life", "is"]]]
a[2][2][0]   # 'Life'
```

| 단계 | 코드 | 결과 |
|---|---|---|
| 1 | `a[2]` | `["a", "b", ["Life", "is"]]` |
| 2 | `a[2][2]` | `["Life", "is"]` |
| 3 | `a[2][2][0]` | `'Life'` |

### 1-3. 슬라이싱: 여러 칸을 한 번에 꺼내기

`[시작:끝]`을 쓰면 여러 칸을 한꺼번에 잘라 올 수 있다. 이걸 **슬라이싱(slicing)** 이라고 한다.

```python
a = [1, 2, 3, ['a', 'b', 'c'], 4, 5]
a[3][:3]   # ['a', 'b', 'c']
```

- `a[3]` → `['a', 'b', 'c']`
- `[:3]` → 처음부터 **3번 칸 직전까지** (0, 1, 2번 칸) → `['a', 'b', 'c']`

> ⚠️ 슬라이싱의 **끝 번호는 포함되지 않는다.** `[:3]`은 0, 1, 2까지만 가져온다.
> "3번 칸 앞에서 멈춘다"라고 외우면 편하다.
>
> 그리고 슬라이싱 결과는 값 하나가 아니라 **리스트**다. `'a'` 하나가 아니라 `['a', 'b', 'c']`가 나온다.

### 1-4. 리스트 더하기

리스트끼리 `+` 하면 **두 리스트가 이어 붙는다.** 숫자처럼 더해지는 게 아니다.

```python
a = [1, 2, 3]
b = [4, 5, 6]
a + b   # [1, 2, 3, 4, 5, 6]
```

### 1-5. 주의: 숫자와 문자는 그냥 더할 수 없다

```python
a = [1, 2, 3]
print(a[0] + a[2])        # 4      ← 숫자 + 숫자는 OK
print(str(a[0]) + 'hi')   # 1hi    ← 문자 + 문자로 바꿔서 OK
```

`a[0] + 'hi'`라고 쓰면 에러(`TypeError`)가 난다. `1`은 숫자고 `'hi'`는 문자라서, 파이썬이 "더하라는 거야, 붙이라는 거야?" 하고 헷갈리기 때문이다.
그래서 `str()`로 숫자를 **문자로 바꿔준 다음** 붙여야 한다.

## 2. 리스트 값 바꾸기 · 지우기

여기서부터는 주식 가격 같은 예제로 연습해 보자.

### 2-1. 값 바꾸기

특정 칸에 새 값을 **대입**하면 그 칸의 값이 바뀐다.

```python
prices = [70000, 71000, 72000, 69000]
prices[3] = 69500
prices   # [70000, 71000, 72000, 69500]
```

3번 칸(69000)이 69500으로 바뀌었다. 사물함 3번 칸을 열고 물건을 갈아 끼운 것과 같다.

### 2-2. `del`로 지우기

`del`은 **번호로** 칸을 지운다.

```python
to_delete = ['CASH', 'BOND', 'ETF']
del to_delete[1]               # 1번 칸('BOND') 삭제
print("한 요소 삭제:", to_delete)   # ['CASH', 'ETF']
```

슬라이싱과 함께 쓰면 여러 칸을 한 번에 지울 수도 있다.

```python
recent = [70000, 71000, 72000, 69000, 73000]
del recent[2:]                 # 2번 칸부터 끝까지 삭제
print(recent)                  # [70000, 71000]
```

`[2:]`처럼 끝 번호를 비워두면 "끝까지"라는 뜻이다.

## 3. 리스트 메서드: 리스트가 가진 기능들

리스트는 스스로 할 줄 아는 기능을 여러 개 가지고 있다. 이런 기능을 **메서드(method)** 라고 하고, `리스트이름.기능이름()` 처럼 점(`.`)을 찍어서 쓴다.

### 3-1. 추가하기: `append()` vs `extend()`

**`append(값)`** 은 리스트 맨 끝에 **값 하나**를 추가한다.

```python
prices = [70000, 71000, 69000]
prices.append(72000)
prices.append(58000)
prices.append([73000, 74000])   # 리스트를 통째로 "한 칸"에 넣는다
print(prices)
# [70000, 71000, 69000, 72000, 58000, [73000, 74000]]
```

마지막 줄을 잘 보자. `[73000, 74000]`이 **리스트 모양 그대로 한 칸**에 들어갔다. 상자를 열지 않고 상자째 사물함에 넣은 셈이다.

상자를 열어서 **안에 든 값을 하나씩** 넣고 싶다면 **`extend()`** 를 쓴다.

```python
price = [70000, 71000, 69000]
price.extend([72000, 73000])
print(price)   # [70000, 71000, 69000, 72000, 73000]
```

| 메서드 | 하는 일 | `[1, 2]`에 `[3, 4]`를 넣으면 |
|---|---|---|
| `append` | 상자째 넣기 | `[1, 2, [3, 4]]` |
| `extend` | 상자를 열어서 하나씩 넣기 | `[1, 2, 3, 4]` |

### 3-2. 정렬하기: `sort()`

**`sort()`** 는 리스트를 작은 것부터 큰 것 순서(**오름차순**)로 정렬한다.

```python
returns = [0.02, -0.01, 0.05, 0.01]
returns.sort()
print(returns)   # [-0.01, 0.01, 0.02, 0.05]
```

문자열은 **사전 순서**(알파벳 순서)로 정렬된다. `reverse=True`를 넣으면 큰 것부터(**내림차순**) 정렬한다.

```python
codes = ["TECH", "FIN", "HEALTH"]
codes.sort()
print(codes)   # ['FIN', 'HEALTH', 'TECH']

codes.sort(reverse=True)
print(codes)   # ['TECH', 'HEALTH', 'FIN']
```

> ⚠️ **`sort()`는 결과를 돌려주지 않는다.**
> `sort()`는 리스트 **자기 자신을 직접 정렬**하고 끝난다. 그래서 정렬된 값을 보려면 정렬한 다음 리스트를 따로 출력해야 한다.
> ```python
> print(codes.sort())   # None  ← 아무것도 안 돌려준다는 뜻
> codes.sort()
> print(codes)          # ['FIN', 'HEALTH', 'TECH']  ← 이렇게 해야 한다
> ```
> `None`은 파이썬에서 **"아무것도 없음"** 을 뜻하는 특별한 값이다.

### 3-3. 뒤집기: `reverse()`

**`reverse()`** 는 리스트 순서를 **거꾸로 뒤집는다.**

```python
codes = ["TECH", "FIN", "HEALTH"]
codes.reverse()
print(codes)   # ['HEALTH', 'FIN', 'TECH']
```

> ⚠️ `reverse()`는 **정렬이 아니다.** 크기나 알파벳은 전혀 보지 않고 **지금 순서를 그대로 거꾸로** 뒤집기만 한다.
> `["TECH", "FIN", "HEALTH"]` → 뒤집으면 → `['HEALTH', 'FIN', 'TECH']`
>
> 큰 것부터 정렬하고 싶다면 `reverse()`가 아니라 `sort(reverse=True)`를 써야 한다.
> `reverse()`도 `sort()`처럼 결과를 돌려주지 않는다.

### 3-4. 위치 찾기: `index()`

**`index(값)`** 은 그 값이 **몇 번 칸에 있는지** 알려준다.

```python
assets = ["CASH", "BOND", "STOCK"]
print("BOND의 인덱스:", assets.index("BOND"))   # 1
```

그런데 리스트에 **없는 값**을 찾으면 에러(`ValueError`)가 난다.
에러가 나면 프로그램이 멈춰버리니까, `try` / `except`로 "에러가 나면 이렇게 해줘"라고 미리 대비할 수 있다.

```python
try:
    assets.index("ETF")          # 없는 값 → 에러 발생!
except ValueError as error:
    print("ETF는 없는 값입니다.", type(error).__name__, error)
# ETF는 없는 값입니다. ValueError list.index(x): x not in list
```

- `try:` 안의 코드를 일단 실행해 본다.
- 에러가 나면 멈추지 않고 `except` 쪽으로 넘어간다.
- `type(error).__name__` → 에러 종류의 **이름** (`ValueError`)
- `error` → 에러 **설명 메시지**

> 💡 에러 메시지 문구는 파이썬 버전마다 조금씩 다를 수 있다. 직접 실행해 보고 확인하자.
> (`try` / `except`는 나중에 "예외처리" 편에서 자세히 다룬다. 지금은 "에러 대비용"이라는 것만 알면 충분하다.)

### 3-5. 끼워 넣기: `insert()`

**`insert(번호, 값)`** 은 원하는 위치에 값을 **끼워 넣는다.** 원래 그 자리에 있던 값들은 한 칸씩 뒤로 밀린다.

```python
assets = ["CASH", "BOND", "STOCK"]
assets.insert(0, "FX")     # 0번 자리에 FX → ['FX', 'CASH', 'BOND', 'STOCK']
assets.insert(3, "GOLD")   # 3번 자리에 GOLD
print("삽입", assets)       # ['FX', 'CASH', 'BOND', 'GOLD', 'STOCK']
```

줄 서 있는 사람들 사이에 새치기하는 모습을 떠올리면 된다. 새치기한 사람 뒤쪽은 다 한 칸씩 밀려난다.

### 3-6. 값으로 지우기: `remove()`

`del`은 **번호로** 지웠다면, **`remove(값)`** 은 **값으로** 지운다.
같은 값이 여러 개 있으면 **맨 앞에 있는 것 하나만** 지운다.

```python
assets = ["CASH", "BOND", "STOCK", "BOND"]
assets.remove('BOND')
print("첫번째 BOND 제거:", assets)   # ['CASH', 'STOCK', 'BOND']
```

뒤에 있는 `'BOND'`는 그대로 남아 있다.

### 3-7. 꺼내면서 지우기: `pop()`

**`pop(번호)`** 은 그 칸의 값을 **꺼내서 돌려주고**, 리스트에서는 **지운다.**
`del`과 다른 점은, 지운 값을 변수에 받아서 쓸 수 있다는 것이다.

```python
# assets는 지금 ['CASH', 'STOCK', 'BOND']
removed = assets.pop(1)               # 1번 칸('STOCK')을 꺼낸다
print("pop 반환", removed)             # STOCK
print("남은 목록:", assets)             # ['CASH', 'BOND']
```

> ⚠️ 바로 앞에서 `remove`를 했기 때문에 리스트가 `['CASH', 'STOCK', 'BOND']`로 바뀐 상태다.
> 그래서 1번 칸은 `'BOND'`가 아니라 `'STOCK'`이다. **코드는 위에서부터 차례로 실행된다**는 걸 항상 기억하자.

### 3-8. 개수 세기: `count()`

**`count(값)`** 은 그 값이 리스트에 **몇 개 있는지** 센다.

```python
print("CASH 등장 횟수:", assets.count("CASH"))   # 1
```

### 3-9. 지우기 3총사 정리

| 방법 | 무엇으로 지우나 | 지운 값을 돌려주나 | 예시 |
|---|---|---|---|
| `del a[i]` | 번호 | ❌ | `del a[1]` |
| `a.remove(x)` | 값 (맨 앞 하나만) | ❌ | `a.remove('BOND')` |
| `a.pop(i)` | 번호 | ⭕ | `x = a.pop(1)` |

## 4. 튜플 (Tuple)

### 4-1. 튜플이란?

튜플은 **리스트와 거의 똑같은데, 한 번 만들면 절대 바꿀 수 없는** 자료형이다.
소괄호 `( )`로 만든다.

비유하자면 **편의점 영수증**이다. 영수증에는 날짜, 상품, 수량이 순서대로 찍혀 있고, 한 번 출력되면 고칠 수 없다.
그래서 튜플은 **거래 기록처럼 바뀌면 안 되는 데이터**를 담을 때 쓴다.

```python
trade = ("2026-01-05", "ETF", "BUY", 3)

print("거래날짜:", trade[0], "수량:", trade[3])   # 거래날짜: 2026-01-05 수량: 3
print("거래 정보 일부:", trade[1:])               # ('ETF', 'BUY', 3)
print("자료형:", type(trade))                     # <class 'tuple'>
print("요소 개수:", len(trade))                   # 4
```

인덱싱(`[0]`), 슬라이싱(`[1:]`), 길이 구하기(`len()`)는 리스트랑 똑같이 쓸 수 있다.

### 4-2. 요소가 하나뿐인 튜플: 쉼표가 핵심!

값이 하나인 튜플을 만들 때는 **반드시 뒤에 쉼표 `,`를 붙여야** 한다.

```python
print(type(('ETF',)))   # <class 'tuple'>   ← 쉼표 있음: 튜플
print(type(('ETF')))    # <class 'str'>     ← 쉼표 없음: 그냥 문자열
```

왜 그럴까? 소괄호 `( )`는 수학에서 `(1 + 2) * 3`처럼 **"이거 먼저 계산해"** 라는 뜻으로도 쓰인다.
그래서 `('ETF')`라고만 쓰면 파이썬은 그냥 괄호로 감싼 문자열 `'ETF'`로 알아듣는다.
쉼표를 붙여야 "아, 이건 튜플이구나" 하고 알아챈다.

> ⚠️ 하나 더 조심할 점: `type('ETF',)`처럼 쓰면 이 괄호는 **`type` 함수를 부르는 괄호**라서 튜플이 만들어지지 않는다.
> 결과는 `<class 'str'>`이다. 튜플의 타입을 보고 싶으면 `type(('ETF',))`처럼 **괄호를 한 겹 더** 감싸야 한다.

### 4-3. 튜플은 바꿀 수 없다

튜플의 값을 지우거나 바꾸려고 하면 에러(`TypeError`)가 난다.

```python
trade = ("2026-01-05", 'ETF', 'BUY', 3)

try:
    del trade[0]                  # 삭제 시도
except TypeError as error:
    print("요소 삭제 불가 :", type(error).__name__)   # TypeError

try:
    trade[0] = "2026-01-06"       # 변경 시도
except TypeError as error:
    print("요소 변경 불가:", type(error).__name__)    # TypeError
```

영수증 내용을 볼펜으로 고칠 수 없는 것과 같다.
리스트에서 쓰던 `append`, `remove`, `sort` 같은 **값을 바꾸는 메서드도 튜플에는 없다.**

### 4-4. 그래도 연결과 반복은 된다

"바꿀 수 없다"면서 `+`는 어떻게 될까?
`+`와 `*`는 원래 튜플을 고치는 게 아니라 **새로운 튜플을 만들어 내는** 것이라서 괜찮다.

```python
trade_id = ('2026-01-06', 'ETF')
quantity_price = (3, 50000)

print("튜플 연결:", trade_id + quantity_price)   # ('2026-01-06', 'ETF', 3, 50000)
print("튜플 반복:", quantity_price * 3)          # (3, 50000, 3, 50000, 3, 50000)
print("튜플 길이:", len(trade_id))               # 2
```

영수증 두 장을 고친 게 아니라, 두 장을 **복사해서 새 종이에 이어 붙인** 거라고 생각하면 된다.

## 5. 딕셔너리 (Dictionary)

### 5-1. 딕셔너리란?

리스트와 튜플은 값을 꺼낼 때 **번호**를 썼다. 그런데 번호만으로는 불편할 때가 있다.
"ETF를 몇 주 가지고 있지?"를 알고 싶은데, ETF가 몇 번 칸에 있는지 매번 기억해야 한다면 너무 귀찮다.

**딕셔너리**는 번호 대신 **이름표(키, key)** 로 값을 찾는다.
영어사전에서 `apple`을 찾으면 `사과`가 나오듯이, **키를 넣으면 값(value)이 나온다.**

```python
price_by_code = {'ETF': 50000, 'BOND': 102000}
#                 키  :  값      키   :  값
```

- 중괄호 `{ }`로 만든다.
- `키: 값` 한 쌍을 쉼표로 구분한다.
- 값을 꺼낼 때는 `딕셔너리[키]`

```python
price_by_code['ETF']   # 50000
```

### 5-2. 무엇을 키로 쓸 수 있을까?

**값**에는 무엇이든(숫자, 문자열, 리스트 ...) 넣을 수 있다. 하지만 **키**에는 규칙이 있다.

```python
price_by_code = {'ETF': 50000, 'BOND': 102000}           # 문자열 키 ⭕
quantity_by_id = {101: 3}                                # 숫자 키 ⭕
price_history = {'ETF': [49000, 50000, 50500]}           # 값이 리스트 ⭕
price_by_day = {('ETF', '2026-01-05'): 50000}            # 튜플 키 ⭕
```

```python
try:
    invalid_key = {['ETF', '2026-01-05']: 50000}         # 리스트 키 ❌
except TypeError as error:
    print("리스트 키 사용 불가:", type(error).__name__)     # TypeError
```

> 💡 **키는 바뀌지 않는 값만 될 수 있다.**
> 서랍장 이름표가 시간이 지나면 저절로 바뀐다고 생각해 보자. 어느 서랍에 뭘 넣었는지 영영 못 찾게 된다.
> 그래서 언제든 바뀔 수 있는 **리스트는 키가 될 수 없고**, 절대 안 바뀌는 **숫자 · 문자열 · 튜플은 키가 될 수 있다.**
> (튜플을 배운 이유가 여기서 하나 나온다!)

### 5-3. 추가 · 수정 · 삭제 · 조회 (CRUD)

데이터를 다루는 네 가지 기본 동작을 앞 글자를 따서 **CRUD**라고 부른다.
**C**reate(추가), **R**ead(조회), **U**pdate(수정), **D**elete(삭제).

```python
holding = {'ETF': 3}
holding['BOND'] = 2                  # 없는 키 → 새로 추가 (Create)
holding['ETF'] = 4                   # 있는 키 → 값 수정 (Update)
holding['CASH'] = [100000, 50000]    # 값으로 리스트도 OK
print("추가/수정:", holding)
# {'ETF': 4, 'BOND': 2, 'CASH': [100000, 50000]}
```

여기서 재밌는 점! **추가와 수정 문법이 완전히 똑같다.**

- 그 키가 **없으면** → 새로 만든다.
- 그 키가 **있으면** → 값을 덮어쓴다.

```python
del holding['BOND']                     # 삭제 (Delete) - 번호가 아니라 키로 지운다
print("삭제 후 :", holding)              # {'ETF': 4, 'CASH': [100000, 50000]}
print("ETF 보유 수량:", holding['ETF'])  # 4   ← 조회 (Read)
```

> ⚠️ 딕셔너리는 **번호(인덱스)로 꺼낼 수 없다.** `holding[0]`처럼 쓰면 "0이라는 키를 찾아줘"라는 뜻이 돼서 에러가 난다.

### 5-4. 키 · 값 · 쌍만 모아 보기: `keys()`, `values()`, `items()`

```python
portfolio = {'ETF': 3, 'BOND': 2, 'CASH': 100000}

print("키 뷰:", portfolio.keys())          # dict_keys(['ETF', 'BOND', 'CASH'])
print("키 목록:", list(portfolio.keys()))   # ['ETF', 'BOND', 'CASH']
print("값 뷰:", portfolio.values())        # dict_values([3, 2, 100000])
print("항목 뷰:", portfolio.items())        # dict_items([('ETF', 3), ('BOND', 2), ('CASH', 100000)])
print("항목 목록:", list(portfolio.items())) # [('ETF', 3), ('BOND', 2), ('CASH', 100000)]
```

| 메서드 | 모아 주는 것 |
|---|---|
| `keys()` | 키만 |
| `values()` | 값만 |
| `items()` | `(키, 값)` 쌍 — **튜플 모양**으로 |

결과 앞에 붙은 `dict_keys(...)` 같은 건 **뷰(view)** 라는 건데, 딕셔너리를 들여다보는 **창문**이라고 생각하면 된다.
리스트처럼 쓰고 싶으면 `list()`로 감싸서 진짜 리스트로 바꾸면 된다.

### 5-5. 반복문으로 하나씩 꺼내기

`for`문과 함께 쓰면 딕셔너리의 내용을 하나씩 꺼내 볼 수 있다.

```python
portfolio = {'ETF': 3, 'BOND': 2, 'CASH': 100000}

for code in portfolio.keys():
    print("종목/자산:", code)
# 종목/자산: ETF
# 종목/자산: BOND
# 종목/자산: CASH

for data in portfolio.items():
    print("data:", data)
# data: ('ETF', 3)
# data: ('BOND', 2)
# data: ('CASH', 100000)

for code, amount in portfolio.items():
    print("키:", code, "값:", amount)
# 키: ETF 값: 3
# 키: BOND 값: 2
# 키: CASH 값: 100000
```

마지막 방법이 제일 많이 쓰인다. `items()`가 `('ETF', 3)` 같은 튜플을 하나씩 주는데,
`for code, amount in ...`이라고 쓰면 그 튜플을 **알아서 쪼개서** `code`에는 `'ETF'`, `amount`에는 `3`을 넣어준다.

(`for`문은 다음 글 "제어문"에서 자세히 다룬다.)

### 5-6. 안전하게 꺼내기: `get()`

딕셔너리에서 값을 꺼내는 방법은 두 가지가 있다.

```python
portfolio = {'ETF': 3, 'BOND': 2, 'CASH': 100000}
print('ETF 조회:', portfolio.get("ETF"), portfolio["ETF"])   # 3 3
```

**있는 키**를 찾을 때는 둘 다 똑같다. 차이는 **없는 키**를 찾을 때 나온다.

```python
print("없는 키 기본 값:", portfolio.get("GOLD", 0), portfolio.get("GOLD"))
# 없는 키 기본 값: 0 None

try:
    print(portfolio['GOLD'])
except KeyError as error:
    print("대괄호로 없는 키 조회:", type(error).__name__)
# 대괄호로 없는 키 조회: KeyError
```

| 방법 | 키가 없으면 |
|---|---|
| `d['GOLD']` | 💥 `KeyError` 에러 → 프로그램이 멈춤 |
| `d.get('GOLD')` | `None` (아무것도 없음)을 돌려줌 |
| `d.get('GOLD', 0)` | 내가 정한 기본값 `0`을 돌려줌 |

비유하자면 `[ ]`는 "**GOLD 서랍 열어!**" 하고 소리치다가 서랍이 없으면 화를 내는 거고,
`get()`은 "**GOLD 서랍 있으면 열어줘, 없으면 0이라고 해줘**" 하고 부드럽게 부탁하는 거다.

> ⚠️ `get`은 **함수(메서드)** 라서 반드시 소괄호 `( )`를 써야 한다.
> `portfolio.get["GOLD"]`처럼 대괄호를 쓰면 `TypeError: 'builtin_function_or_method' object is not subscriptable` 에러가 난다.
> 해석하면 "함수한테는 대괄호를 쓸 수 없어요"라는 뜻이다.

## 6. 내가 실제로 했던 실수 모음 🐛

실습하면서 직접 틀렸던 부분들이다. 비슷한 실수를 하는 사람이 많을 것 같아서 정리해 둔다.

| 실수한 코드 | 무엇이 문제였나 | 고친 코드 |
|---|---|---|
| `asset.index("BOND")` | 변수 이름은 `assets`인데 `s`를 빠뜨림 → `NameError` | `assets.index("BOND")` |
| `price = [...]` 만들고 `prices.append(...)` | 만든 리스트와 쓴 리스트 이름이 다름 → **엉뚱한 리스트**에 값이 추가됨 | 이름을 하나로 통일 |
| `portfolio.get["GOLD"]` | `get`은 함수인데 대괄호를 씀 → `TypeError` | `portfolio.get("GOLD")` |
| `type('ETF',)` | 함수 호출 괄호라서 튜플이 안 만들어짐 → `str` | `type(('ETF',))` |
| `print(..., type(error), __name__)` | `__name__`이 에러 이름이 아니라 엉뚱한 값 | `type(error).__name__` |
| `a[-1]` 결과를 `5`라고 적음 | `[1, 2, 3]`의 마지막은 `3` | `# 3` |
| `a[3][:3]` 결과를 `'a'`라고 적음 | 슬라이싱 결과는 **리스트** | `# ['a', 'b', 'c']` |
| `reverse()` 결과를 정렬된 순서로 적음 | `reverse`는 정렬이 아니라 **뒤집기만** 함 | `# ['HEALTH', 'FIN', 'TECH']` |
| `pop(1)` 결과를 `BOND`라고 적음 | 바로 앞의 `remove`로 리스트가 이미 바뀐 걸 깜빡함 | `# STOCK` |

> 💡 **교훈**
> 1. 주석에 결과를 적을 때는 **머릿속으로 짐작하지 말고 꼭 실행해서 확인**하자.
> 2. 노트북은 셀을 **위에서부터 차례로** 실행한다. 앞 셀에서 바뀐 값이 뒤 셀에 그대로 이어진다.
> 3. 변수 이름 오타(`asset` / `assets`, `price` / `prices`)는 생각보다 정말 자주 한다.

## 7. 마무리 요약

- **리스트 `[ ]`**: 순서 있음, 수정 가능. 번호(0부터!)로 꺼낸다.
  - 추가 `append` / `extend` / `insert`, 삭제 `del` / `remove` / `pop`, 정렬 `sort`, 뒤집기 `reverse`
  - `sort()`, `reverse()`는 결과를 돌려주지 않는다 (`None`)
- **튜플 `( )`**: 순서 있음, **수정 불가.** 바뀌면 안 되는 기록용.
  - 요소가 하나면 `('ETF',)`처럼 **쉼표 필수**
- **딕셔너리 `{ }`**: **키 → 값**으로 찾는다.
  - 키는 바뀌지 않는 값(숫자 · 문자열 · 튜플)만 가능, 리스트는 불가
  - 없는 키는 `[ ]` → 에러, `get()` → `None` 또는 기본값

다음 글에서는 `if`, `for`, `while` 같은 **제어문**을 정리해 보겠다.
