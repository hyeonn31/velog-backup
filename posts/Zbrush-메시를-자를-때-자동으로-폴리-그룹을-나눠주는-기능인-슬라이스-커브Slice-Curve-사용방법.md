## 슬라이스 커브란
ZBrush에서 메시를 자를 때 사용하는 브러시 도구로,
자동으로 폴리그룹을 나눠주는 기능이 있다!

### 📌 슬라이스 커브의 특징
폴리곤을 나누면서 새로운 폴리그룹을 생성함.
메시를 실제로 분리하지 않고 폴리그룹만 나누어줌.
브러시처럼 사용 가능하며, 커브 형태로 자를 수 있음.
### 🛠️ 슬라이스 커브 사용 방법
1️⃣ Ctrl + Shift를 누른 상태에서 마우스 오른쪽 클릭(또는 펜 드래그)
2️⃣ 선을 그리면 그 부분에서 메시가 잘림 (기본적으로는 직선)
3️⃣ Alt 키를 누르면 곡선 추가 가능!
4️⃣ 커브를 확정하면 자동으로 폴리그룹이 나뉨

### ✅ 슬라이스 커브를 사용할 때 주의할 점!
실제 메시가 분리되지는 않음. SubTool로 나누려면 Group Split을 사용해야 함.
디바이드(Divide)를 적용한 상태에서 사용하면 예상과 다르게 작동할 수도 있음.
만약 그룹이 나뉘지 않았다면 Tool → Polygroups → Auto Groups를 눌러 확인!
### 💡 슬라이스 커브 vs 크리즈 커브 비교
|기능|슬라이스 커브|크리즈 커브|
|:---|:---:|:---:|
|**목적**|폴리그룹 나누기|엣지 크리즈 유지|
|**자동 그룹 생성**|✅ O|❌ X|
|**실제 메시 분할?**|	❌ X (폴리그룹만)|❌ X
|**곡선 자르기 가능?**|✅ O (Alt 키 사용)|✅ O (Alt 키 사용)
