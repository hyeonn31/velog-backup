, : 라이트박스 열기 닫기

T: 2.5D <-> 3D 모드 변경
ctrl + n : 초기화(오브젝트 복제되어 안사라질때)

s : 브러쉬 사이즈 조절 
shift + f : 폴리프레임 보이게/안보이게

---
ctrl + d : 디바이드 생성
shift + d : 디바이드 하위 레벨
d : 디바이드 상위레벨
w : 기즈모

---

ctrl + shift : 하이드기능(숨기기)

ctrl : 마스크 기능

x : Symmetry(대칭빨간점)

----
1번 : 브러쉬 반복

shift + 서브툴 브러쉬 클릭 : 전체 색 끄기/켜기

art : 오브젝트 변환 키
