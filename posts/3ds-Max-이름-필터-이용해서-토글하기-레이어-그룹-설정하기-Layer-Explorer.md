# 📕 이름 필터 이용해서 토글하기

![](https://cdn.jsdelivr.net/gh/hyeonn31/velog-backup@main/assets/fe42e90d18b3b585.png)
맥스로 uv unwrap작업을 하다보면 로우폴과 하이폴이 각각 있게 된다.

예시로 low폴리곤의 오브젝트만 잡고 싶다면
## 검색창에 **[*_low]** 로 솔팅하기
![](https://cdn.jsdelivr.net/gh/hyeonn31/velog-backup@main/assets/ce0804c930b4b6ba.png)

이렇게 low가 붙은 오브젝트만 위로 솔팅된다.

# 📕 레이어 그룹 설정하기 (Layer Explorer)


1. 레이어 창에서 Default -> Layer Explorer로 변경한다.
![](https://cdn.jsdelivr.net/gh/hyeonn31/velog-backup@main/assets/6d73c26a2c651ad5.png)
[변경된 레이어 창]
![](https://cdn.jsdelivr.net/gh/hyeonn31/velog-backup@main/assets/c8fd59de72ce32cb.png)

2. 그 후 검색창에 원하는 솔팅 단어를 입력한다. 
나는 high폴리곤의 hair부분을 그룹 설정 해보겠다. 
![](https://cdn.jsdelivr.net/gh/hyeonn31/velog-backup@main/assets/eeb1caa0ab001efb.png)


3. 원하는 레이어를 선택하고 Create New Layer를 클릭한다. 

![](https://cdn.jsdelivr.net/gh/hyeonn31/velog-backup@main/assets/6b90af26dc18ce3e.png)
밑에 새로운 그룹이 생긴것을 알 수 있다. 
![](https://cdn.jsdelivr.net/gh/hyeonn31/velog-backup@main/assets/78c6f5eb7d262dfb.png)

오른쪽 마우스 rename을 통해 그룹이름을 지정해준다. 
![](https://cdn.jsdelivr.net/gh/hyeonn31/velog-backup@main/assets/542b755735b2f149.png)
