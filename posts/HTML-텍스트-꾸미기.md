```
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta http-equiv="X-UA-Compatible" content="IE=edge">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>텍스트 꾸미기</title>
</head>
<body>
  <h3>텍스트 꾸미기</h3>
  <hr>
  <b>진하게</b><br>
  <strong>중요한</strong><br>
  <em>이탤릭체로 중요함 강조</em><br>
  <i>폰트 이탤릭 변경</i><br>
  <i><b>폰트 진하게 이탤릭체로 변경</b></i><br>
  보통문자 <small>한 단계 작은문자</small><br>
  <del>삭제</del><br>
  <ins>추가</ins><br>
  보통문자의 <sup>윗첨자</sup><br>
  보통문자의 <sub>아래첨자</sub><br>
  <mark>하이라이팅</mark><br>
</body>
</html>
```

> 새롭게 알게 된 점:
small : 한 단계 작은 문자
del : 삭제 (가운데 줄)
ins : 추가 (밑줄)
sup : 윗첨자
sub : 아래첨자
mark : 하이라이팅
